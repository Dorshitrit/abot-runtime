## Client Compatibility

Delegated Planner events retain the existing `planner.plan.*` names and
`stage=development_plan` payload field. This is a client presentation contract,
not evidence of a separate request path or semantic routing state. A
`planner.graph` advisory is only a returned role result and does not create
those plan events.

## Regression Rule

Test behavior at the owning boundary. Do not encode one observed role or tool
sequence as the general rule. A cross-cutting change must cover default direct
response, delegation, Worker and root capability execution, advisory return,
native continuation, client events, failure finalization, persisted output,
and an unrelated-policy negative control as applicable.
