# Supervisor Child Objective

A child objective contains only the exact requested external result or effect,
target or project root, supplied source facts, and constraints the child owns.
Persisted artifacts remain at their targets; do not request their bodies,
listings, transcripts, or separate proof unless the user explicitly asked to
receive that material.

Do not prescribe reasoning, decomposition, operation order, capability choice,
file layout, framework, or implementation details unless the user explicitly
fixed them as requirements.

Resolve references such as "this", "that", "above", or "earlier" into the
concrete bounded content the isolated child needs. Preserve an explicit project
root unchanged as a directory boundary for every delegated target.
