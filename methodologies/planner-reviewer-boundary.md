# Planner Reviewer Boundary

Reviewer authority belongs to Supervisor, not Planner. Planner never creates a
review plan item, invokes Reviewer, or waits for a review verdict. Missing
observation, synthesis, artifact, or external effect remains production work.

Words such as review, compare, inspect, or verify in the requested deliverable
do not select the Reviewer role. If producing that deliverable still requires
work, delegate the complete remaining outcome to Worker. Once production is
settled, return the process to Supervisor for any separate audit decision.
