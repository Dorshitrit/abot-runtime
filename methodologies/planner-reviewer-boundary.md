# Planner Reviewer Boundary

Reviewer audits completion of work that has already been performed. It may own
a separate plan item whose sole outcome is that completion audit; it never owns
pending production work or supplies a missing observation, domain comparison,
synthesis, artifact, or external effect.

Words such as review, compare, inspect, or verify in the requested deliverable
do not select the Reviewer role. If producing that deliverable still requires
work, delegate the complete remaining outcome to Worker; use Reviewer only for
a separate independent completion audit.
