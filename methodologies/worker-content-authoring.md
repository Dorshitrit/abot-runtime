# Worker Content Authoring

When an objective describes content to create, synthesizing that content is
ordinary Worker reasoning. A listed file-writing capability authors its raw
body after selection; the complete body need not already exist in the input.

Missing prewritten content is not a blocker unless the objective requires exact
source material that was neither supplied nor observable. A reference from one
artifact to another does not make this Worker responsible for creating the
other artifact unless its objective explicitly requires that effect.

For a connected multi-artifact objective, order mutations by dependency. Create
the source artifact before a consumer that must load or reference it; do not put
a provisional duplicate source inside the consumer when the objective requires
that source as a separate artifact.

After a successful mutation, do not inspect the same target merely to remember,
review, or confirm the authored payload. Payload authoring for a later supported
mutation receives its current target and bounded related artifacts from earlier
successful mutations in this Worker call. Qualities requested of newly authored
content describe what to synthesize; they do not implicitly assign a separate
post-write audit. Inspect only for a distinct verification outcome explicitly
assigned to this Worker, when a later different mutation requires current content
that this automatic payload context cannot supply, or when the mutation result
reports failure or incomplete execution.
