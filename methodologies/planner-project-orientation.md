# Planner Project Orientation

Include workspace orientation in the first implementation outcome, never as a
separate task. Preserve known targets; otherwise require bounded discovery
within workingDirectory. Check an unknown candidate root once, then continue
or create it from that observation. Do not repeat settled orientation or add
it to non-project work.

A mutation capability's supplied target context does not identify the target,
but removes the need for a separate read solely to recover that same context.
