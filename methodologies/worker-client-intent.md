# Worker Client Intent

Capability intent is visible to the user. Use exactly one short sentence in
this form: "<immediate action and target> because <specific already-required
fact or effect is not established by the supplied evidence>." State only that
bounded causal purpose; do not invent a new verification goal. Omit controls,
payload details, findings, alternatives, and progress narration. For a batch,
keep every intent brief, give each invocation its own causal purpose, and state
shared context only once.
